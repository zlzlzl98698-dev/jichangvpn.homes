## 四、网络底层传输技术与抗封锁原理深潜

选择机场不仅是比拼价格，更应理解底层网络通信工程。只有弄清数据是如何跨越国境传输的，才能在遇到网络波动时具备自主判断能力。

### 1. 为什么“直连中转”在晚高峰必定卡顿断流？
很多月均 2-5 元的廉价机场采用公网直连或公网中转架构。其数据流向为：
<div style="background: #f8fafc; border: 1px solid #e2e8f0; border-radius: 8px; padding: 0.9rem 1.2rem; margin: 1rem 0; font-family: monospace; font-size: 0.95rem; color: #1e293b; text-align: center;">
  用户设备 ➔ <span style="color:#64748b;">[公网直连]</span> ➔ 国内普通VPS中转 ➔ <span style="color:#ef4444; font-weight: bold;">[过境公网 GFW 审查与 QoS 丢包]</span> ➔ 境外落地服务器
</div>
在白天地广人稀时，公网出口尚能维持；但一到晚间 20:00–23:00 的全国上网高峰期，国际公网出口带宽严重拥塞。运营商骨干网路由器会触发 **QoS（服务质量控制）限速机制**，丢弃 UDP 数据包并将非特权 TCP 链接降速。此时用户不仅看 4K 频繁缓冲，连普通网页都会发生长时间等待超时。

### 2. IEPL 与 IPLC 内网专线的本质区别
专线机场之所以稳定，是因为其租用了**运营商级跨境局域网专线光缆**：
- **IPLC (International Private Leased Circuit)**：国际私有租用线路。通常为端到端的两点专用通信，完全绕过公共互联网，属于物理层/链路层的局域网直连。
- **IEPL (International Ethernet Private Line)**：国际以太网专线。基于以太网标准的二层专线，具备极高的带宽扩展性与弹性调度能力。

**核心优势**：
- **不过公网 GFW 审查节点**：跨境数据在海底光缆内部专线传输，根本不存在公网 GFW 敏感干扰问题。
- **抖动与丢包接近零**：从国内入口机房到境外落地机房网络质量等同于局域网互通，晚高峰网络表现与白天完全一致。

### 3. 通信协议代际差异：Shadowsocks vs VLESS + Reality
代理协议决定了流量在被运营商监测时的“伪装能力”：
- **第一代：Shadowsocks / VMess (AEAD)**：虽然对数据载荷进行了对称加密，但由于其流量握手具有特殊的熵值特征，近年来极易被深度包检测（DPI）算法识别并进行针对性端口阻断。
- **新一代：VLESS + Reality (XTLS 体系)**：彻底摒弃了传统伪装方式，直接“借用”大型正规互联网企业（如 Apple、Microsoft、Amazon）的合法 TLS 证书与 SNI 握手特征。中间监测设备只能看到用户在与微软或苹果服务器进行标准的 TLS 1.3 握手，无法在不解密正常商业流量的前提下进行阻断，抗封锁能力跃升。

### 4. AI 与流媒体风控机理：机房 ASN 库阻断与原生住宅 IP
很多用户常问：“*为什么我的节点能正常打开 Google，但打开 ChatGPT 却提示 Access Denied，看 Netflix 只有自制剧？*”
- **ASN 库匹配**：数据中心（如 AWS、DigitalOcean、Linode）的 IP 地址在国际网络自治系统（ASN）中被公开标记为 Commercial/Hosting。OpenAI 与流媒体平台默认将此类 IP 判定为代理机房并直接下发封禁验证。
- **原生与住宅 IP (Residential IP)**：优质机场会在落地端采购本土住宅 ISP（如香港 HKBN、台湾 Hinet、日本 So-net）提供的宽带 IP，或者配置专属 DNS 解锁流媒体分流服务器，使得请求流量伪装为当地普通家庭宽带用户，实现 100% 顺畅免降级访问。

## 六、网络性能科学自测与数据验证方法论

在日常交流中，很多用户常被不良测评博主的单次截图忽悠。建立科学客观的网络测速与评价体系，是每一个理性出海用户的必备素养。

### 1. Ping 延迟、Jitter 抖动与丢包率的真实影响
衡量一条代理线路的优劣，绝对不能只看单一的下载速度，必须建立“四维指标模型”：

| 指标维度 | 理想数值标准 | 实际用户体验影响 | 劣质线路表现特征 |
|:---|:---|:---|:---|
| **RTT 往返延迟 (Ping)** | 亚太 < 60ms / 美区 < 160ms | 决定网页首屏打开速度、终端输入字符回显响应 | 延迟超过 250ms 会出现明显的点击迟滞 |
| **Jitter 抖动方差** | < 3ms (专线) / < 10ms (中转) | 决定语音会议是否卡字、外服竞技游戏是否瞬移 | 抖动忽高忽低会导致 TCP 拥塞控制频繁减半窗口 |
| **Packet Loss 丢包率** | **严格为 0.0%** (晚高峰 < 0.5%) | 决定视频是否断流转圈、长连接是否自动重连 | 丢包率一旦达到 3% 以上，4K 播放将彻底崩溃 |
| **单线程下行带宽** | > 50Mbps (满足4K超清码率) | 决定单文件下载、网页大图渲染与视频缓冲速度 | 白天下行飞快、晚间骤降至 5Mbps 以下（公网QoS） |

### 2. 动手使用开源脚本对节点进行科学打分
若您希望亲自对购买的机场节点进行全方位体检，建议在本地终端或 Linux 机器上借助以下开源工具实测：

#### ① 真实带宽与多并发压测 (Speedtest CLI)
避免使用网页版受浏览器 JavaScript 引擎与渲染性能限制，直接使用官方 CLI 工具：
```bash
# 测试指定境外 Speedtest 节点（例如香港服务器）
speedtest -s 1536 --progress=yes
```
通过观察测试过程中输出的 `Latency` 抖动曲线与 `Download` 瞬时速率波动，若速度曲线呈直线爬升并稳定在顶部，说明后端专线带宽充足；若速率忽上忽下剧烈波动，说明存在节点超售或带宽争抢。

#### ② 流媒体与 AI 解锁自动化检测脚本
借助开源社区成熟的检测脚本（如 `RegionRestrictionCheck`）：

## 七、跨境电商与海外自媒体运营防封专项

对于外贸独立站站长、亚马逊 (Amazon) 店铺运营者、TikTok 跨境带货博主以及海外社交媒体矩阵（X / Instagram / Facebook）从业者，网络环境的安全性直接关联到核心资产的存亡。

### 1. TikTok 国际版防黑屏与伪装度检测
TikTok 客户端对环境的审查极其严苛。很多新手即使挂了梯子，打开 App 依然是一片黑屏或“零播放”：
- **核心封锁维度**：
  1. **SIM 卡运营商 MCC 码检测**：插入中国大陆 SIM 卡（+86）会被 App 内部底层接口直接阻断；
  2. **系统语言、时区与 GPS 经纬度**：手机时区未调整为节点对应时区，或者打开了系统定位权限；
  3. **IP 纯净度与欺诈分 (Fraud Score)**：使用被大量羊毛党轮番滥用的垃圾机房 IP。
- **合规操作 SOP**：
  - 拔出手机内中国 SIM 卡（或使用纯海外 eSIM 卡）；
  - 关闭手机系统“定位服务 (Location Services)”，并将系统语言与时区严格调整为落地节点所在地区（如美东时区）；
  - 打开 `whoer.net` 或 `iphey.com` 进行环境伪装度自检，确保伪装度评分达到 **100%**。

### 2. 独立固定原生 IP 对跨境电商防关联的极端重要性
对于亚马逊、PayPal、Stripe 以及外贸银行账户，频繁更换登录 IP 是触发“异常登录锁定”与“封店审查”的第一大诱因：
- **普通共享节点的致命陷阱**：一个普通机场的日本节点，后端出口可能挂载着数百甚至数千名普通用户的混合流量。一旦其中某位用户从事违规操作导致该出口 IP 被亚马逊或 PayPal 列入黑名单，同节点下的所有商业账户均可能遭遇**关联封店**的灭顶之灾。
- **应对方案**：商务出海团队强烈建议采购服务商提供的 [独立原生固定 IP 定制服务](/brands/guangsu/)，由服务商分配专属的独立带宽与固定住宅 IP，确保该 IP 仅供本公司团队独家使用，彻底斩断账号关联风险。

## 八、软路由与家庭全屋透明代理部署指南

对于追求极致体验的用户，在全屋主路由器上配置透明代理，可实现手机、电脑、智能电视（Apple TV、Sony TV）与家用游戏主机（PS5、Switch、Xbox）连接 WiFi 即自动出海，无需在每台设备上逐个繁琐安装配置软件。

### 1. Apple TV / Google TV / 游戏主机免客户端配置
- **体验升华**：Apple TV 上的 Netflix 与 YouTube 客户端可实现开机秒开，遥控器直接点播 4K HDR 杜比视界，彻底告别投屏卡顿。
- **游戏联机低延迟**：PS5 或 Switch 下载海外数字版游戏时，软路由透明代理可满速跑满家庭千兆宽带；联机对战时通过配置 UDP 转发加速，将 NAT 类型优化为 NAT Type 1 / Open，彻底告别联机匹配失败。

### 2. OpenClash 与 PassWall 模式选择与 DNS 避坑
在软路由常见插件（OpenClash 与 PassWall2）中，合理的模式选择直接关系到网络吞吐与 CPU 占用率：
- **模式推荐：Meta-TUN 虚拟网卡模式**：相比传统的 GfwList 模式或简单的 Redir 端口转发，基于 Mihomo 内核的 TUN 虚拟网卡模式在软路由 Linux 系统内以二层网络接管数据包，对 UDP 游戏数据包和多播协议兼容性极佳，CPU 负载均衡性能卓越。
- **关键防坑：DNS 防污染与死循环规避**：
  - 许多软路由新手经常遭遇“国内网络瘫痪”的问题。核心原因在于**软路由本地 DNS 与 AdGuardHome、Dnsmasq 之间形成了端口重定向死循环**。
  - **最佳解法**：在 OpenClash 中勾选 `使用 Dnsmasq 转发`，开启 `Fake-IP` 解析模式，让国内域名直接由运营商上游 DNS 毫秒级直连解析，仅被代理名单内的域名交由海外安全 DoH 解析，兼顾极速与防污染。

## 九、主流客户端全平台配置与进阶调优实操手册

选好优质机场后，客户端的正确配置是发挥专线性能的关键。许多用户网络慢并非机场问题，而是客户端分流模式与 DNS 设置不当导致的。

### 1. Windows / macOS 桌面端：Clash Verge Rev 黄金调优法则
[Clash Verge Rev](/clash/verge/) 是目前兼顾颜值、Mihomo (Meta) 内核稳定性与跨平台支持的最佳现代客户端：
- **安装与正版校验**：前往 [Clash Verge 官方下载专区](/clash/download/) 获取最新 Release 安装包。在 Windows 下建议安装带有 Service Mode（服务模式）的完整版本。
- **订阅导入三步法**：
  1. 复制机场后台的“Clash 订阅链接”；
  2. 打开 Verge Rev，进入左侧 `订阅 (Subscription)` 标签页，在上方地址栏粘贴链接并点击 `导入 (Import)`；
  3. 导入成功后右键该配置，选择 `使用 (Use)`。
- **关键调优设置**：
  - **模式选择**：日常务必勾选 **Rule（规则分流）**，绝对不要长期挂着 Global（全局）。
  - **开启 TUN 模式**：点击左下角设置开启 `TUN Mode`，配合系统服务模式，可以完全接管终端命令行（Git/SSH/Terminal）与外服游戏进程的网络流量，免除手动配置本地 HTTP 代理端口的麻烦。
  - **DNS 防泄露调优**：在设置中开启 `内置 DNS (Built-in DNS)`，建议 Fake-IP 模式，将本地 DNS 查询转发至海外安全 DoH/DoT 服务器（如 Cloudflare `1.1.1.1` 或 Google `8.8.8.8`），彻底根绝运营商 DNS 劫持。

### 2. iOS 苹果端：Shadowrocket（小火箭）避坑与配置
在 iPhone 与 iPad 设备上，由于中国大陆 App Store 政策限制，必须借助海外 Apple ID 获取代理工具：
- **获取途径**：准备一个美区或港区 Apple ID，在 App Store 搜索 `Shadowrocket` 购买下载（售价约 $2.99 美金）。切勿相信国内贴吧网页上的所谓“破解版”，严防恶意木马注入。
- **一键订阅导入**：登录机场用户中心，直接点击 `一键导入 Shadowrocket` 即可自动唤起 App 完成节点拉取；若不支持一键唤起，可在小火箭首页点击右上角 `+`，类型选择 `Subscribe`，在 URL 栏粘贴机场订阅链接并保存即可。
- **全局路由设置**：在小火箭首页下方将“全局路由”从 `配置` 确认为默认的分流配置，切勿选为 `代理`，否则国内流量全走海外专线，数日内即可耗尽月度流量配额。

### 3. Android 安卓端：v2rayNG 与 Clash Meta for Android
安卓平台开源生态丰富，推荐以下两种方案：
- **方案一 (轻量直观)**：安装 [v2rayNG](/clash/recommend/)。支持扫描二维码或一键导入订阅，内存占用极小（不足 50MB），对老旧机型兼容极佳。在左侧菜单开启“分应用代理”，勾选仅代理 Chrome、Twitter、Telegram 等指定应用，国内微信淘宝完全不走底层 V2Ray 核心，既省电又省流量。
- **方案二 (高级规则)**：安装 [Clash Meta for Android (CMFA)](/clash/meta/)。支持完整的 Mihomo 内核特性，适合需要复杂分流组（如不同流媒体走不同国家落地）的高级玩家。

## 十、AI 生产力与流媒体解锁专项实战

随着生成式 AI 与 4K 影音渗透入日常工作与娱乐，现代出海用户的诉求已经从“能打开网页”升级为“深度业务无感运行”。以下为核心场景的落地配置指南：

### 1. ChatGPT 与 Claude 3.5 Sonnet 防封号实操指南
- **区域黑名单机制**：OpenAI 官方从未开放对中国大陆及香港/澳门地区的直接访问服务。因此，凡是接入香港节点的请求，均会被 Cloudflare 反向代理拦截并返回 403 错误代码。
- **分流最佳实践**：
  - 在 Clash 客户端的策略组（Proxy Groups）中，找到针对 OpenAI 或 AI 的分流规则组；
  - 手动将该分流组绑定至 **新加坡 (Singapore)**、**日本 (Tokyo)**、**台湾 (Taipei)** 或 **美国 (United States)** 专线节点；
  - 尽量保持登录该账号的节点地区固定，避免在一分钟内先后从日本切换到美国，触发 OpenAI 的“异地突变地理位置”反欺诈风控。
- **Claude 严格风控防御**：Anthropic 公司对数据中心机房 IP 采取“零容忍”封号政策。使用 Claude 时，务必确认所选节点在 [流媒体与 AI 解锁矩阵](#_4-ai-生产力与流媒体解锁状态) 中显示为 `支持`（原生广播/住宅 IP），避免刚充值订阅就被冻结账号。

### 2. Netflix 4K HDR 与 Disney+ 影音全库解锁
- **非自制剧 (Non-Originals) 判定法则**：若登录 Netflix 搜索《绝命毒师》(Breaking Bad) 或《老友记》(Friends) 能够正常搜出并播放，说明该节点属于**原生全区解锁**；若只能搜出 Netflix 官方自制剧（带有红色 N 标的原创影视），说明该节点 IP 已被网飞识别为代理机房，被降级为仅供自制剧播放。
- **码率顺畅标准**：Netflix 4K 超高清串流要求持续稳定带宽不低于 25Mbps。专线节点（如 [光速云 IEPL](/brands/guangsu/)）凭借平稳的 TCP 窗口机制与低抖动，可实现 4 秒内加载完成并维持 2160P 稳定不降画质。

## 十一、购买机场五步避坑铁律与排雷手册

在购买和使用机场过程中，请牢记以下经过无数老玩家血泪总结的黄金铁律：

```
第一步：核验运营历史 (优先选择运营3年以上的稳定老牌)
   │
第二步：拒绝超低价终身诱惑 (不买大促百元永久无限量套餐)
   │
第三步：警惕年付折算陷阱 (分清月付实价与年付折算均价)
   │
第四步：首购坚持单月实测 (验证本地宽带高峰期真实延迟)
   │
第五步：配置多订阅灾备方案 (主力专线 + 平价备用双保险)
```

1. **铁律一：分清“年付折算均价”与“真实月付价格”**  
   部分不良商家在宣传海报上打出“仅需 5 元/月”，结账时才发现必须一次性年付 60 元或两年付 120 元，根本不提供 5 元单月支付选项。购买前务必认准计费周期，避免冲动消费。
2. **铁律二：远离任何宣称“99元终身无限流量”的商家**  
   跨境带宽是按兆（Mbps）向运营商按月缴纳高额机房月租的物理消耗品。任何声称数十元即可享受“终身不限流量、无限高速”的平台，其商业模型必然是庞氏资金盘，资金链一旦断裂便会迅速拔线跑路。
3. **铁律三：严防节点“虚标倍率”与流量偷跑**  
   部分机场在普通节点标示 1.0x 倍率，但在高速节点暗中设置为 3.0x、5.0x 甚至 10.0x 倍率。这意味着用户下载 1GB 视频实际上会被后台扣除 10GB 流量。务必在客户端或管理后台仔细核查节点倍率。
4. **铁律四：支付安全防范与合规自保**  
   国内正规机场多采用聚合免签支付通道（支付宝/微信扫码）。支付时请留意商户名称是否异常；对于外贸或大额充值用户，建议优先选用支持 USDT 等虚拟资产结账的服务商，保障支付安全。
5. **铁律五：善用现代客户端的“规则分流”功能**  
   在 [Clash Verge Rev](/clash/verge/) 等客户端中，务必选择 **Rule（规则模式）** 而非 Global（全局模式）。规则模式下访问百度、淘宝、B站等国内服务会自动直连，既不消耗珍贵的代理专线流量，又能保证国内 App 的秒级加载。

## 十二、常见故障九步标准排障流程 (SOP)

当您在日常使用中突发断网或节点全红时，请严格按照以下标准九步排查法，95% 以上的问题均可在 2 分钟内自行解决：

```
① 检查本地网络物理连通性 ──▶ ② 校验本地系统时间误差 ──▶ ③ 检查客户端系统代理勾选
               │
               ▼
④ 排查本地 7890 端口占用 ──▶ ⑤ 检查安全软件防火墙拦截 ──▶ ⑥ 右键执行订阅链接增量更新
               │
               ▼
⑦ 检查套餐余额与流量是否耗尽 ──▶ ⑧ 切换不同国家落地节点 ──▶ ⑨ 重启客户端或切换 TUN 模式
```

1. **第一步：脱离代理测试裸网连通性**  
   暂时退出代理软件，打开国内主流网站（如百度、Bilibili）。若国内网站同样打不开，说明属于本地 WiFi 中断或家庭宽带欠费，优先修复本地物理连接。
2. **第二步：强制同步本地系统时间（首要元凶）**  
   进入系统设置，关闭自动同步时间后再重新打开，强制与 Windows 或 Apple 时间服务器同步。若本地时间误差超过 60 秒，TLS 加密握手必定失败导致节点全部超时。
3. **第三步：确认系统代理开关状态**  
   在 Clash 或 v2rayN 主界面确认 `System Proxy (系统代理)` 是否处于高亮启用状态。在 Windows 设置 ➔ 网络和 Internet ➔ 代理中，确认地址是否正确指向 `127.0.0.1:7890`。
4. **第四步：排查本地代理端口冲突**  
   若同时开启了多个网络加速器或旧版代理软件，可能导致 `7890` 端口被强行占用。打开终端运行 `netstat -ano | findstr 7890`，排查是否有冲突进程。
5. **第五步：排查杀毒软件拦截**  
   360、火绒或 Windows Defender 偶尔会将代理内核（Mihomo/Xray）误报为木马并静默切断外联。将代理客户端目录加入杀毒软件白名单。
6. **第六步：增量更新订阅节点配置**  
   机场可能因临时网络维护更换了入口或落地域名。在客户端右键点击订阅，选择“Update/更新配置”，拉取最新可用节点列表。
7. **第七步：登录机场后台核查流量配额**  
   核对账户是否欠费、月度流量是否已经跑完（用尽后节点会自动切断）。
8. **第八步：手动切换落地国家测试**  
   可能特定香港或日本机房正在遭受临时 DDoS 攻击，手动切换至新加坡、美国或台湾节点测试连通性。
9. **第九步：重启 TUN 驱动或切换核心模式**  
   若浏览器能打开但终端无法联网，重启 TUN 模式网卡驱动；更多高级系统排障请参阅本站 [Clash 故障排障专属手册](/clash/troubleshoot/)。

## 十四、核心高频疑难问题深入解答 (FAQ)

### Q1: 专线机场比普通公网机场贵出不少，普通人真有必要买专线吗？
**结论：视使用时段与业务敏感度而定。**  
如果您仅在白天偶尔查阅海外资料、看看 Twitter 简讯，普通的优质中转机场足以满足需求；但如果您在 **晚间 20:00–23:00** 有频繁出海需求（如追剧、看 4K 直播、打国际外服游戏、参加远程视频会议），公网中转的高丢包率会引发严重的卡顿断流。此时多花十元购买具备 IEPL 专线的服务商（如 [光速云](/brands/guangsu/)），换来的无感流畅体验是绝对超值的。

### Q2: 为什么我的机场节点在测速软件里 Ping 延迟只有 30ms，但实际打开网页却很慢？
**结论：ICMP 延迟不等于真实数据吞吐。**  
测速面板显示的 Ping 通常为客户端到国内中转接入机房的往返延迟（RTT），仅能证明本地到入口通畅；而打开网页需要经过“国内入口 ➔ 跨境专线 ➔ 境外落地 ➔ 目标网站服务器”全链路，并受限于落地节点的 DNS 解析速度、TCP 握手时长与当前出口带宽负载。因此，评估机场质量必须看 **实际下载速度（Mbps）与丢包率（Packet Loss）**，切勿单纯迷信小数值 Ping。

### Q3: 为什么同一家机场在电信宽带下飞快，换到移动宽带或校园网后就严重卡顿甚至连不上？
**结论：受制于国内各运营商的互联互通瓶颈与公网出口策略。**  
中国移动与中国广电的国际公网出口带宽相对薄弱，且在晚高峰对跨省跨网流量（如移动宽带访问电信骨干机房）限制严格。优质机场会在全国部署多线 BGP 入口（电信、联通、移动三网就近接入）以消除跨网损耗；如果您的宽带是移动网络，建议优先挑选标明具备 **三网 BGP 接入** 的专线机场。

### Q4: 节点连接正常却打不开 ChatGPT，提示“Access Denied”或“1020 Error”如何解决？
**结论：属于落地节点 IP 被 OpenAI 封锁，需通过分流规则切换地区。**  
1. OpenAI 严禁香港、澳门等大中华区 IP 访问，如果您的分流走到了香港节点，必定报错。
2. 即使连接新加坡或美国节点，若该节点属于数据中心机房段且滥用过频，也会被 Cloudflare 拦截。  
**解决步骤**：在客户端中将节点手动切换至日本原生、台湾或美国专用住宅节点；若仍无法解决，可参考 [Clash 故障排查手册](/clash/troubleshoot/) 清理浏览器 LocalStorage 缓存。

### Q5: 机场出现哪些反常征兆意味着即将跑路？
**结论：警惕促销清凉、管理失联与批量拔线三大信号。**  
1. **反常巨幅降价**：平日不打折的服务商突然发布“充值 1 年送 2 年”、“99元永久不限流量套餐”，多为现金流枯竭套现的前兆。
2. **官方沟通渠道禁言**：Telegram 交流群开启全员禁言，客服工单多日无人回复。
3. **节点大面积超时超一周未修复**：声称上游被查，长期不恢复节点。遇到此类情况请参阅本站 [跑路预警与黑名单情报中心](/resources/warning/)。

### Q6: 购买按量计费（不限时流量包）和按月计费哪个更经济？
**结论：月出海流量低于 20GB 者选不限时，高频使用者选月付。**  
月付套餐无论流量是否用完，到期必定清零，相当于每月有固定持有成本；而不限时流量包（如光速云 147 元 247GB）虽然单价看似稍高，但只要不用完就永久有效。如果您只是把梯子当作查资料、收邮件的备用工具，按量不限时套餐能摊薄数年使用成本，是极致省钱的最佳选择。

### Q7: 为什么强烈推荐用户使用规则分流模式而非全局模式？
**结论：保护专线流量、提升国内网速并防范金融账号风控。**  
在全局代理（Global）模式下，您访问微信、淘宝、网银等国内 App 的流量全部会绕道海外服务器，不仅导致国内应用响应极慢，更会瞬间耗尽宝贵的专线流量配额；更为严重的是，国内各大银行与支付机构会因异地跨国登录触发安全风控冻结账户。使用 **Rule 规则模式** 则可实现“国外走代理、国内走直连”的无感分流。

### Q8: 客户端显示“所有节点全部超时 (Timeout)”，最快的排查动作是什么？
**结论：依次执行“同步系统时间 ➔ 更新订阅 ➔ 切换内核模式”。**  
超过 70% 的全红超时是由**本地电脑/手机系统时间与互联网时间误差超过 60 秒**导致的，底层 TLS 加密握手会因时间不同步直接阻断。校准北京时间后，进入客户端右键点击订阅执行“Update/更新”，基本可立即恢复。若仍有问题，请查阅 [Clash 节点超时排错全解](/clash/troubleshoot/trouble-timeout-p1/)。
